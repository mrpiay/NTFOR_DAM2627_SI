## Qué incluye cada entrega

| UD | Entrega | Qué incluye |
|---|---|---|
| UD3 | Scripts básicos para automatizar tareas de administración en Linux | Prácticas de navegación y administración mediante terminal. Estructuras de ficheros y directorios creadas y gestionadas. Usuarios, grupos y permisos configurados. Procesos y servicios administrados. Copias de seguridad realizadas y restauradas. Tareas automatizadas. Análisis de la información de monitorización del sistema. Scripts básicos para automatizar tareas de administración. |
| UD4 | Scripts sencillos de administración en Windows (PowerShell) e informe de monitorización | Prácticas de administración de Windows. Gestión de ficheros, usuarios, grupos y permisos. Configuración de procesos y servicios. Copias de seguridad y recuperación. Tareas programadas. Informes de monitorización. Configuración de directivas locales. Utilización básica de PowerShell y del Registro. Scripts sencillos de administración y ejercicios de gestión del almacenamiento. |

## Qué se aprende y cómo se evalúa en cada unidad

Resultados de aprendizaje (RA) y criterios de evaluación (CA) de cada unidad, con el instrumento con el que se evalúa cada criterio.

### UD3 · Sistema operativo Linux. Administración y configuración.

**RA3** · Gestiona la información del sistema identificando las estructuras de almacenamiento y aplicando medidas para asegurar la integridad de los datos

| Criterio | Cómo se evalúa | Peso |
|---|---|---|
| **CA3.1** Se han comparado sistemas de ficheros. | Prueba escrita | 5 % |
| **CA3.2** Se han identificado la estructura y la función de los directorios del sistema operativo. | Prueba escrita | 5 % |
| **CA3.3** Se han utilizado herramientas en entorno gráfico y comandos para localizar información en el sistema de ficheros. | Tabla de observación | 10 % |
| **CA3.4** Se han creado diferentes tipos de particiones y unidades lógicas. | Tabla de observación | 5 % |
| **CA3.5** Se han realizado y restaurado copias de seguridad. | Tabla de observación | 5 % |
| **CA3.6** Se han planificado y automatizado tareas. | Tabla de observación | 5 % |
| **CA3.7** Se han instalado y evaluado utilidades relacionadas con la gestión de información. | Tabla de observación | 10 % |

**RA4** · Gestiona sistemas operativos utilizando comandos y herramientas gráficas, y evaluando las necesidades del sistema

| Criterio | Cómo se evalúa | Peso |
|---|---|---|
| **CA4.1** Se han configurado cuentas de usuario locales y grupos. | Tabla de observación | 5 % |
| **CA4.2** Se ha asegurado el acceso al sistema mediante el uso de directivas de cuenta y directivas de contraseñas. | Tabla de observación | 10 % |
| **CA4.3** Se han identificado, arrancado y detenido servicios y procesos. | Tabla de observación | 5 % |
| **CA4.4** Se ha protegido el acceso a la información mediante el uso de permisos locales y listas de control de acceso. | Tabla de observación | 5 % |
| **CA4.5** Se han utilizado comandos para realizar las tareas básicas de configuración y administración del sistema. | Tabla de observación | 10 % |
| **CA4.6** Se ha monitorizado el sistema. | Tabla de observación | 10 % |
| **CA4.7** Se han instalado y evaluado utilidades para el mantenimiento y la optimización del sistema. | Tabla de observación | 5 % |
| **CA4.8** Se han evaluado las necesidades del sistema informático en relación con el desarrollo de aplicaciones. | Prueba escrita | 5 % |
