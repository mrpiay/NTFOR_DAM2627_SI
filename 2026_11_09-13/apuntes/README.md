## Dónde consultar

- **VirtualBox:** el manual oficial, en inglés: [VirtualBox User Manual](https://www.virtualbox.org/manual/).
- **Ubuntu Server:** la documentación oficial, en inglés: [Ubuntu Server documentation](https://documentation.ubuntu.com/server/).
- **GRUB:** el manual oficial, en inglés: [GNU GRUB Manual](https://www.gnu.org/software/grub/manual/grub/grub.html). Lo de `/etc/default/grub` está en el apartado *Simple configuration handling*.
- **Windows:** la documentación oficial de Microsoft, en español: [requisitos de Windows 11](https://learn.microsoft.com/es-es/windows/whats-new/windows-11-requirements), [particiones de un disco con UEFI y GPT](https://learn.microsoft.com/es-es/windows-hardware/manufacture/desktop/configure-uefigpt-based-hard-drive-partitions) y [`bcdedit /enum`](https://learn.microsoft.com/es-es/windows-hardware/drivers/devtest/bcdedit--enum).
- **Software libre:** [qué es el software libre](https://www.gnu.org/philosophy/free-sw.es.html), de la Free Software Foundation, en español.
